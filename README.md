# Vehicle Scrapping - Kerala Vendor Price Quotation Portal

Live GitHub Page: **[https://ppsaheed.github.io/1page_cta/](https://ppsaheed.github.io/1page_cta/)**

A modern, fast, mobile-friendly 1-page quotation CTA portal for bulk scrap vehicle purchase rate submissions in Kerala.

## Features
- **Real-Time Dynamic Pricing**: Automatically multiplies unit offers by quantities (28 vehicles across 16 models) and computes line totals + grand total.
- **Direct WhatsApp CTA**: Encodes vendor contact info, offered rates, sub-totals, and notes into an official WhatsApp message to `+91 98950 60003`.
- **One-Click Clipboard Copy**: Easy copy button for desktop vendors or sharing via email / SMS.
- **Mobile Optimized**: Floating sticky totals bar and touch-friendly numeric keypads for scrap yard operators.
- **Zero Build Dependencies**: Pure HTML, CSS, and Vanilla JavaScript hosted seamlessly via GitHub Pages.
